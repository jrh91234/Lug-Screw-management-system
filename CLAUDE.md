# Working instructions for Claude Code sessions

## Pull requests
- Once a PR's CI checks are green and there are no unresolved review comments that need a fix, merge it (squash) without waiting to be asked again — don't leave it sitting open for the user to come back and merge manually.
- If GitHub's native auto-merge is available for the repo, prefer enabling it right after opening the PR so it merges itself as soon as checks pass. If enabling it fails because the repo setting isn't turned on, just merge directly once checks are green instead of blocking on it.
