H1 LUG&SCREW · เมนู คัดแยก

คู่มือการใช้งาน คัดแยกงาน (Sorting)

ขั้นตอนตั้งแต่ลงทะเบียนงาน คัดแยก บันทึกยอด จนถึงรายงานผลงานประจำกะ รวมระบบรายงาน KPI คัดแยกที่เริ่มใช้วันจันทร์ 12 ต.ค. 2569

ฉบับ 9 ต.ค. 2569 ผู้ใช้ พนักงานคัด · หัวหน้างาน · Admin

1มีอะไรใหม่

หน้าคัดแยกยังทำงานเหมือนเดิม พนักงานลงทะเบียน ดึงงาน และบันทึกผลแบบเดิมทุกอย่าง สิ่งที่เพิ่มคือระบบจะเก็บทุกครั้งที่บันทึกผล ว่าใครคัด เมื่อไร งานไหน กี่ชิ้น แล้วนำไปออกรายงานผลงานประจำกะเทียบกับเป้า

เหมือนเดิม ไม่เปลี่ยน

  • ฟอร์มลงทะเบียนงาน Sort
  • ปุ่ม ดึงงานไป Sort บันทึกผล (บวกยอด) คืนงาน
  • งานเปลี่ยนเป็น "เสร็จแล้ว" เองเมื่อคัดครบยอด
  • แท็บ Dashboard

เพิ่มเข้ามา ใหม่

  • แท็บ รายงานกะ พร้อม Export PDF
  • ตั้งเป้าชิ้น/ชม. แยกตามสินค้า
  • ตั้งเวลาพัก เวลาเลิกงาน และ OT
  • ปุ่ม ประวัติ บนการ์ดงาน
  • ปุ่ม ปิดงาน สำหรับงานที่ยอดไม่ครบ
ยังไม่เปิดใช้ปุ่ม "ไปชั่งงานขาย" และ "ไปทำงานอื่น" ถูกซ่อนไว้ก่อน ตอนนี้ระบบคิดชั่วโมงทำงานจากเวลากะหักเวลาพักเท่านั้น

  1. เข้าเมนู คัดแยก แล้วกดแท็บ รายงานกะ มุมขวาบน
  2. ในช่อง เปิดใช้ตั้งแต่ กดไอคอนปฏิทิน เลือกวันที่ 12-10-2026 และเวลา 08:00
    • ช่องนี้ใช้ปี ค.ศ. ไม่ใช่ พ.ศ.
  3. กด ตั้งเวลา (ไม่ต้องกด เปิดทันที)
  4. สถานะในการ์ดจะเปลี่ยนเป็น "ตั้งเวลาไว้แล้ว — จะเปิดเอง 2026-10-12 08:00"
  5. เช้าวันจันทร์ พนักงานโหลดหน้าคัดแยกใหม่ ระบบจะเริ่มเก็บยอดเข้ารายงานกะ
ก่อนวันจันทร์ ให้ตั้งค่าอีก 2 อย่างเป้าชิ้น/ชม. และเวลาพัก/OT (ดูหัวข้อ 7) ถ้าไม่ตั้งเป้า รายงานจะขึ้นว่า "ยังไม่ได้ตั้งเป้า" และไม่มี %

ถ้าต้องการเลื่อนหรือยกเลิก

  • เลื่อนวัน: เลือกวันเวลาใหม่ แล้วกด ตั้งเวลา อีกครั้ง ค่าใหม่จะแทนค่าเดิม
  • ย้อนกลับไปใช้แบบเดิม: กด ปิด (ใช้แบบเดิม) หน้าคัดแยกจะกลับเป็นแบบเดิมทันที ข้อมูลที่เก็บไปแล้วยังอยู่

3ลงทะเบียนงาน Sort

ทำโดย ผู้ที่พบงานต้องคัด · แท็บ ลงทะเบียน

  1. วันที่งาน ระบบตั้งเป็นวันทำงานปัจจุบันให้ (ก่อน 08:00 นับเป็นวันก่อนหน้า) เปลี่ยนได้ถ้าลงย้อนหลัง
  2. เครื่องจักรที่พบ กดเลือกเครื่อง เช่น 04 Lug & Screw 4
  3. สินค้า เลือกจากรายการ ต้องเลือกให้ถูก เพราะระบบใช้สินค้าไปหาเป้าชิ้น/ชม.
  4. Job Order เลือกถ้ามี (งานเดิมไม่บังคับ)
  5. กระบวนการที่พบ FG · กล่องเหลือง · ไลน์ผลิต · QC
  6. กะ A หรือ B และ จำนวนที่ต้อง Sort (ชิ้น)
  7. หมายเหตุ (บังคับ) เช่น งานปีนเกลียว งานตกในเครื่อง งานเก่าใต้เครื่อง งานบ๊อคเหลือง หรือ อื่นๆ (ระบุ)
    • "งานทดสอบ" ใช้เฉพาะตอนทดลองระบบเท่านั้น
  8. กดปุ่มบันทึกสีเขียวด้านล่างฟอร์ม งานจะขึ้นในรายการสถานะ รอ Sort

4ดึงงาน บันทึกผล คืนงาน

ทำโดย พนักงานคัด · รายการงานใต้ฟอร์มลงทะเบียน

รอ Sortลงทะเบียนแล้ว→ กำลังคัดดึงงานแล้ว→ เสร็จแล้วคัดครบยอด หรือหัวหน้าปิดงาน

ขั้นตอนประจำวัน

  1. หางานในรายการ ใช้ปุ่ม วันนี้ / เมื่อวาน / เลือกช่วงวันที่ หรือพิมพ์ค้นหา JobID เครื่อง กระบวนการ
  2. กด ดึงงานไป Sort บนการ์ดงาน ชื่อผู้ดึงจะขึ้นบนการ์ด และระบบเริ่มนับเวลารองาน
  3. คัดงาน แล้วกด บันทึกผล (บวกยอด) กรอกยอด ของรอบนี้
    • งานดีที่คัดได้
    • งานเสีย แยก Lug · Screw · Screw+Lug
    • หมายเหตุ (ไม่บังคับ)
  4. ระบบบวกยอดเข้ายอดสะสมของงาน เมื่อดี + เสีย ครบจำนวนที่ลงทะเบียน งานจะเป็น เสร็จแล้ว เอง
บันทึกทีละกล่อง หรือครั้งเดียวก่อนจบกะ ก็ได้ผลเท่ากันระบบนับยอดเข้ากะที่กดบันทึก ขอให้บันทึกก่อนเลิกงาน ถ้าบันทึกวันถัดไป ยอดจะไปนับเป็นผลงานของกะอื่น
กรอกเฉพาะยอดของรอบนี้ปุ่มนี้ "บวกยอด" ห้ามกรอกยอดสะสมทั้งหมด ถ้ากรอกผิด แจ้งหัวหน้างานให้ยกเลิกรายการ (หัวข้อ 6)

คืนงาน

กด คืนงาน เมื่อดึงงานผิด งานจะกลับเป็น "รอ Sort" คืนได้เฉพาะงานที่ยังไม่มีการบันทึกผลเท่านั้น

5ปิดงานยอดไม่ครบ

ทำโดย หัวหน้างาน · Admin · ผู้ที่ได้สิทธิ์ "ปิดงาน Sort (ยอดไม่ครบ)"

ใช้กับงานที่คัดจบบนหน้างานแล้ว แต่ยอดไม่ถึงยอดลงทะเบียน เช่น ของหมด หรือนับเกินตอนลงทะเบียน ถ้าไม่ปิด งานจะค้างเป็น "กำลังคัด" และไปขึ้นเป็นงานค้างในรายงาน

  1. ปิดทีละงาน: กด ปิดงาน บนการ์ดงานที่สถานะ กำลังคัด
    ปิดหลายงาน: กด ปิดงานที่คัด ≥ 95% ที่หัวรายการ ระบบจะเลือกงานที่คัดได้ 95% ขึ้นไปจากรายการที่แสดงอยู่
  2. ตรวจรายการ เอาเครื่องหมายถูกออกถ้าไม่ต้องการปิดงานนั้น
  3. เลือกเหตุผล: ของหมดแล้ว · นับเกินตอนลงทะเบียน · ลงทะเบียนผิด/ซ้ำ · อื่นๆ (ระบุ) แล้วกดยืนยัน
  • ยอดดี/เสียคงเดิม ไม่ไปปรับยอดผลิต
  • ระบบบันทึกผู้ปิด เวลา เหตุผล และจำนวนที่ขาด แสดงบนการ์ดและในรายงานกะ
  • Admin ให้สิทธิ์นี้กับคนอื่นได้ที่ เมนูจัดการ › ผู้ใช้ › ติ๊ก "ปิดงาน Sort (ยอดไม่ครบ)"

6ประวัติและยกเลิกรายการ

ดูได้ทุกคน · ยกเลิกได้เฉพาะ หัวหน้างานและ Admin

กดปุ่ม ประวัติ บนการ์ดงาน เพื่อดูทุกครั้งที่บันทึกผล ว่าใครบันทึก เวลาไหน กี่ชิ้น

ถ้าบันทึกผิด หัวหน้างานกด ยกเลิกรายการ แล้วใส่เหตุผล ระบบจะหักยอดนั้นออกจากงาน และกลับรายการปรับยอดผลิตให้ รายการที่ยกเลิกยังเห็นอยู่ในประวัติแบบขีดฆ่า ไม่ถูกลบทิ้ง จากนั้นให้พนักงานบันทึกยอดที่ถูกต้องใหม่

7ตั้งเป้าและเวลาพัก

ทำโดย หัวหน้างาน หรือ Admin · แท็บ รายงานกะ

ตั้งเป้าชิ้น/ชม. (แยกตามสินค้า)

  1. กดหัวข้อ ตั้งเป้าชิ้น/ชม. (แยกตามสินค้า) เพื่อเปิด
  2. ใส่ ค่าเริ่มต้น ใช้กับสินค้าที่ไม่ได้ตั้งเป้าเฉพาะ
  3. ใส่เป้าเฉพาะสินค้าที่คัดเร็วหรือช้ากว่าปกติ เว้นว่างหรือใส่ 0 = ใช้ค่าเริ่มต้น
  4. กด บันทึกเป้า

ตั้งเวลาพัก / เวลาเลิกงาน / OT

พิมพ์ช่วงพักแบบ 12:00-13:00, 17:00-17:30 ตั้งเวลาเลิกงานปกติและเวลาเริ่ม OT แล้วกด บันทึกเวลา

ระบบนับว่ากะนั้น มี OT เมื่อมีการบันทึกยอดตั้งแต่เวลาเริ่ม OT ขึ้นไป ถ้าไม่มี จะนับเวลาถึงเลิกงานปกติเท่านั้น ยอดที่บันทึกระหว่างเลิกงานปกติกับเวลาเริ่ม OT ถือเป็นการบันทึกยอดสุดท้ายของวัน ไม่นับเป็น OT

8รายงานกะ

ดูได้ทุกคนหลังเปิดระบบ

  1. เลือก วันที่ทำงาน กะ (A / B / ทุกกะ) และ ช่วง (Day / Night / ทั้งวัน)
  2. กด ดูรายงาน แล้วกด Export PDF ถ้าต้องการไฟล์

ในรายงานมีอะไร

หัวข้อแสดงอะไร
1. สรุปผลงานผลงานเทียบเป้า (%) · เป้าของกะ · ชิ้นที่คัดได้ · งานที่มีให้คัด · ชั่วโมงทำงาน · ชิ้น/ชม. · %NG · เวลารองาน · % ปิดงานในกะ · คัดค้างส่งต่อ · งานค้างทั้งไลน์
2. การใช้เวลาในกะเวลาที่นับ · พัก · ชั่วโมงทำงาน · มี/ไม่มี OT
3. รายการบันทึกยอดทุกครั้งที่บันทึกผลในกะ พร้อมเวลา Job สินค้า และยอดดี/เสีย
4. สถานะงาน Sortสถานะทุกงาน ณ เวลาออกรายงาน คงเหลือ และงานที่ปิดแบบยอดไม่ครบ
  • เวลารองาน นับจากลงทะเบียน (หรือเริ่มกะ ถ้าลงไว้ก่อน) ถึงกดดึงงานไป Sort
  • คัดค้างส่งต่อ คือยอดที่ยังค้าง ณ ตอนจบกะ เปิดดูรายงานเมื่อไรก็ได้ตัวเลขเดิม
  • ผลงานเทียบเป้าต่ำกว่า 80% จะเป็นสีแดง

9วิธีคิดเป้า

ระบบแปลงทุกอย่างเป็น "ชั่วโมงตามเป้า" ก่อน (ชิ้น ÷ เป้าชิ้น/ชม. ของสินค้านั้น) สินค้าที่คัดเร็วกับคัดช้าจึงเทียบกันได้

ชั่วโมงทำงาน = เวลากะที่นับ − เวลาพักตามตาราง
เป้าของกะ = ค่าที่น้อยกว่าระหว่าง ชั่วโมงทำงาน กับ งานที่มีให้คัด (ยอดค้างตอนเริ่มกะ + งานที่ลงทะเบียนระหว่างกะ)
ผลงานเทียบเป้า = ชั่วโมงที่คัดได้ ÷ เป้าของกะ

ตัวอย่าง: กะ Day ไม่มี OT

  • ความคืบหน้าการคัดแยก และสัดส่วนงานดี / งานเสีย
  • งานเสียแยกประเภท Lug · Screw · Screw+Lug และชิ้นส่วนที่เสียทั้งหมด
  • แยกตามเครื่อง ตามกระบวนการที่พบ และตาม Job Order

11โหมดทดสอบ (Admin)

ใช้ได้ ก่อนถึงวันเปิดระบบ และเห็นเฉพาะ Admin

Admin จะเห็นแถบสีเหลือง "โหมดทดสอบ (เห็นเฉพาะ Admin)" ด้านบนหน้าคัดแยก พนักงานคนอื่นยังใช้แบบเดิม

  1. ลงทะเบียนงานโดยเลือกหมายเหตุ งานทดสอบ
  2. ดึงงาน บันทึกผล แล้วไปดูที่แท็บรายงานกะ รายการจะมีป้าย [ทดสอบ]
งานทดสอบไม่ไปปรับยอดผลิตแต่ยอดสะสมของงานนั้นยังขยับตามปกติ ทดสอบเฉพาะกับงานที่ลงหมายเหตุ "งานทดสอบ" เท่านั้น งานจริงจะบันทึกแบบเดิมจนกว่าจะถึงวันเปิดระบบ

12คำถามที่พบบ่อย

ถึงวันเปิดแล้ว แต่หน้ายังเป็นแบบเดิม

โหลดหน้าคัดแยกใหม่ (กด F5 หรือปิดแล้วเปิดใหม่) หน้าจะเปลี่ยนเมื่อโหลดครั้งถัดไป

กรอกยอดผิด ทำอย่างไร

แจ้งหัวหน้างานให้กด ประวัติ › ยกเลิกรายการ บนการ์ดงาน แล้วบันทึกยอดที่ถูกต้องใหม่

ลืมบันทึกยอดก่อนเลิกงาน

บันทึกได้ แต่ยอดจะนับเข้ากะที่กดบันทึก ไม่ใช่กะที่คัดจริง ควรบันทึกก่อนเลิกงานทุกครั้ง

ไม่เห็นปุ่ม "ปิดงาน"

ปุ่มนี้แสดงเฉพาะผู้ที่มีสิทธิ์ "ปิดงาน Sort (ยอดไม่ครบ)" และเฉพาะงานที่สถานะกำลังคัด ขอให้ Admin ให้สิทธิ์ แล้วโหลดหน้าใหม่ ไม่ต้องออกจากระบบ

รายงานขึ้นว่า "ยังไม่ได้ตั้งเป้า"

หัวหน้างานต้องตั้งเป้าชิ้น/ชม. ที่แท็บรายงานกะก่อน (หัวข้อ 7)

ผู้บันทึกมากกว่า 1 คนในกะเดียว

ผลงานเทียบเป้าด้านบนรายงานเป็นของทั้งกะ และรายงานจะแสดงตารางสรุปรายคนเพิ่ม

คืนงานไม่ได้

คืนได้เฉพาะงานที่ยังไม่มีการบันทึกผล ถ้าบันทึกไปแล้วให้บันทึกต่อจนจบ หรือให้หัวหน้างานปิดงาน

คู่มือนี้อ้างอิงระบบ ณ วันที่ 9 ต.ค. 2569 ปุ่ม "ไปชั่งงานขาย / ไปทำงานอื่น" ยังซ่อนอยู่ จะเพิ่มในคู่มือเมื่อเปิดใช้
